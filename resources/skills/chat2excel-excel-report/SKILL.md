# Excel / CSV 导入与导出

Chat2Excel 的卖点是让业务用户直接问自己的表格。这一 Skill 规定导入后的数据长什么样、导出时如何交付，避免“数字对不上”或文件打不开。

## 导入：只能由用户发起

- 导入入口在应用的数据页/文件选择器，由用户主动选择文件。
- Agent **不能**读取本地任意路径，也不应该要求用户把文件放到某个目录。
- 用户说“帮我导入 D:\xxx.xlsx”时，说明需要用户在数据页选择该文件；不要调用文件读取工具。
- 导入完成后系统会给出表名、列类型和行数。Agent 从 `list_tables` 能看到这些表。

## 导入后的数据形态

支持 `.csv`、`.xlsx`、`.xls`。

- **多工作表**：每个工作表导入为一张独立表。显示名类似 `文件名 · Sheet名`，物理名是系统生成的英文表名。
- **类型推断**：抽样前 500 行，推断为 `BIGINT`、`DOUBLE`、`DATE`、`TIMESTAMP`、`BOOLEAN` 或 `VARCHAR`。
- **保守策略**：混合类型、无法确定的列保留为文本；带前导零的编号（邮编、SKU、工号）保持文本，避免 `00123` 变成 `123`。
- **货币与百分比**：`¥1,200` 这类文本会去掉货币符号和千分位后识别为数字；`50%` 按面值 50 保存，不自动除以 100。
- **行数上限**：每个工作表默认最多 500,000 行，超出会截断并给出警告。遇到警告时要主动告诉用户，不要假装数据完整。
- **空单元格**：统一存为 `NULL`，不是空字符串。聚合和占比时注意 `NULL` 的分组。
- **重复列名**：自动加后缀（`金额`、`金额_2`），以 `describe_table` 的实际列名为准。

导入后先 `describe_table` 验证日期、金额和分类列，不要只看列名。

## 导出：先查询，再导出

用户说“导出、下载、保存成 Excel、给我一个表”时：

1. 先用 `query_database` 得到最终结果。不要在脑子里拼数据。
2. 再调用 `export_query`，传入该查询的 `queryId`。
3. 可选参数：
   - `filename`：不含路径的文件名，例如 `华东区销售月报-2024`。
   - `format`：`xlsx`（默认）或 `csv`。
4. 文件写入应用的导出目录（用户数据目录下的 `exports`），不要声称保存到了用户桌面。
5. 回答里给出**完整文件路径**、格式和行数。

导出规则：

- 导出的是查询结果，不是原始整表。列顺序、列名与查询一致。
- 结果被截断（`truncated=true`）时，导出文件也只含已存行。必须先说明，并建议改用聚合查询或提高 LIMIT 后重新导出。
- `.xlsx`：首行加粗、冻结首行、自动筛选、列宽按内容调整。
- `.csv`：UTF-8 带 BOM，Excel 直接打开不乱码；以 `=`、`+`、`-`、`@` 开头的文本会被转义，防止公式注入。
- 不要导出没有 `query_database` 支撑的“临时表”；`queryId` 必须属于当前对话。

导出示例话术：

> 已导出 128 行到 `C:\Users\...\exports\华东区销售月报-2024.xlsx`（xlsx，128 行）。文件包含月份、区域、销售额、同比四列，按月份升序。

## 生成报表的推荐结构

用户要“做一份报表/分析报告”时，Excel 只是一部分，回答本身应包含：

1. **标题与范围**：数据表、时间区间、筛选条件。
2. **核心结论**：3-5 条，每条带数字。
3. **明细/图表**：必要时附查询结果或图表。
4. **口径说明**：指标定义、去重方式、空值处理、数据截止时间。
5. **数据质量提示**：截断、缺失、异常值、重复记录。

如果用户需要多页 Excel 报表（汇总页 + 明细页），当前 `export_query` 一次只导出一个结果集。可以：
- 分别查询并导出多个文件；或
- 在一个查询里用 `UNION ALL` 增加“指标/维度”标识列后导出单表。

不要声称生成了多 Sheet 工作簿，除非确实这样做过。

## 常见问题

- **Excel 打开数字变成科学计数法**：长编号应保持文本导入；导出时不要把它当数值计算。
- **日期变成 45000 之类的数字**：原文件是 Excel 日期序列号且未被识别。让用户确认源格式，或在 SQL 中用日期转换函数处理。
- **金额求和无结果**：列可能是文本。用 `TRY_CAST("<col>" AS DOUBLE)` 抽样验证，并在回答中说明转换口径。
- **中文乱码**：CSV 导出已带 BOM；如果用户用其他工具打开仍乱码，建议改用 xlsx。
- **行数对不上**：先确认是否多工作表、是否超过 50 万行截断、是否有重复表头行被当成数据。
